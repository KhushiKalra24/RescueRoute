# RescueRoute – Disaster Response and Evacuation Management System

**Team Name:** Crisis Coders  
**Project Type:** Data Structures and Algorithms Project  
**Technology:** C and C++

## About the Project

RescueRoute is a disaster response and evacuation management system designed to simulate emergency handling in Dehradun, Uttarakhand.

The system helps prioritize emergency requests, assign available ambulances, identify hospitals with available capacity, and find routes using graph-based Breadth-First Search (BFS).

## Key Features

- Emergency prioritization using a Priority Queue.
- Ambulance availability and assignment management.
- Hospital capacity checking and assignment.
- Road network representation using an Adjacency List Graph.
- Route finding using Breadth-First Search (BFS).
- CSV file handling for dataset management.

## Data Structures and Algorithms Used

| Concept | Application |
|---|---|
| Priority Queue | Emergency prioritization |
| Graph (Adjacency List) | Road network representation |
| BFS | Route finding |
| Queue | BFS traversal |
| Vectors and Maps | Data storage and management |
| File Handling | Reading CSV datasets |
